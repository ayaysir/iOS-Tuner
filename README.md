## 기술 스택

- Swift
- UIKit
- CoreData
- AudioKit
- Google AdMob
- In-app Purchases (StoreKit) 등

## 기능

- 평균율과 순정율에 모두 대응할 수 있는 튜닝 기능
  - 전문 음악인들에게 안성맞춤입니다.
  - 고정된 주파수가 아닌 다양한 주파수를 기준으로 튜닝할 수 있습니다.
- 음을 재생할 수 있는 주파수(음높이) 테이블
  - 테이블 표시 및 해당 주파수 음을 들을 수 있습니다.
- 나의 튜닝 결과를 기록하고 열람할 수 있는 통계 기능

## 특징

- 다국어 지원: 한국어, 영어, 일본어
- 아이패드, 아이폰 및 아이팟 터치(7세대) 전 기종에 대응하는 유니버설 디자인
- iCloud 연동을 통해 나의 Apple 기기간 튜닝 기록 결과를 동기화할 수 있음
- 다크 모드 지원

## 문제점 및 해결

- 통계 페이지를 위한 자동 녹음 기능 구현
  - 무음을 감지해서 악기를 연주했다가 몇 초 이상 악기/보컬을 연주하지 않으면(중지하면) 자동으로 해당 연주에 대한 기록이 저장되도록 하였습니다.
  - 사용자가 의식해서 수동으로 녹음 액션을 하지 않더라도 자동으로 기록이 저장되므로 편리합니다.
